# water

1本あたりの容量（mL）、本数、合計金額から総容量（mL）と100mLあたりの値段（円）を計算するコマンドです。飲み物などの容量・入り数が異なる商品の単価を比較したいときに利用できます。

## 必要環境

- Python 3

## インストール・準備

リポジトリをクローンし、`water` コマンドに実行権限を付与します。

```bash
git clone https://github.com/Yuuki-Fujisawa/water.git
cd water
chmod +x water
```

## 使い方

`./water` を実行し、画面の案内に従って数値を入力します。

```bash
./water
```

### 実行例

```text
=== 1mLあたりの値段 計算ツール ===
1本あたりの容量（mL）を入力してください: 500
本数を入力してください: 6
合計の値段（円）を入力してください: 540
----------------------------------------
総容量: 3,000.0 mL
100mLあたりの値段: 18.00 円
----------------------------------------
```
