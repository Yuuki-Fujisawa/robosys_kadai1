# water

1本あたりの容量（mL）、本数、合計金額から総容量（mL）と100mLあたりの値段（円）を計算するコマンドです。飲み物などの容量・入り数が異なる商品の単価を比較したいときに利用できます。

## 必要環境

- Python 3

## インストール・準備

リポジトリをクローンし、`water` コマンドに実行権限を付与します。

```bash
git clone https://github.com/Yuuki-Fujisawa/water.git
cd robosys_kadai1
chmod +x water
```

## 使い方

`./water` とだけ打ってEnter を押し、1行につき「容量(mL) 本数 値段(円)」を半角スペース区切りで入力して Enter を押します。入力が終わったら、新しい行で Ctrl キーを押しながら D を押します。

```bash
./water
500 6 600
```
（入力後に Ctrl + D を押すと、100mLあたりの値段が出力されます）

### 出力例

```text
20.00
```
複数行まとめて入力することもできます。

```bash
./water
500 6 600
2000 6 1200
```
### 出力例

```text
20.00
10.00
```

## エラー処理・終了ステータス

```text
正常に計算できた場合は終了ステータス 0 を返します。

空行、項目数の不足・過剰、数値以外、0以下の容量・本数、負の値段が入力された場合は標準エラー出力（stderr）にエラーメッセージを出力し、終了ステータス 1 を返します。
```

（Ctrl + D を押すと、各行の計算結果が順番に出力されます）
